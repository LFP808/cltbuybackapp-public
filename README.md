# Buyback Operations Dashboard

A small operations dashboard for an electronics buyback workflow. It covers appointment booking, customer communication, inventory intake, invoice pricing, and payout tracking.

## What it includes

- meetup scheduling and appointment workflow
- customer records and inbound communication thread
- device intake and inventory tracking by IMEI/serial
- pricing and invoice workflows
- P/L and cash-flow views
- admin settings for scheduling and inventory rules

## Stack

- Next.js 15 (App Router)
- Supabase for auth, Postgres, and realtime
- Twilio for SMS/voice integrations
